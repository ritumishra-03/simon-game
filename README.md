# Simon's Game

A browser-based memory game built using HTML, CSS, and JavaScript.

## About the Project

Simon's Game is a memory-based game where the player has to remember and repeat an increasing sequence of colors.

The game becomes more challenging as the level increases.

## Features

- Random color sequence generation
- Increasing difficulty with each level
- User input validation
- Game-over detection
- Interactive color buttons

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Play

1. Press any key to start the game.
2. Watch the color sequence carefully.
3. Click the buttons in the same order.
4. Each successful round increases the level.
5. The game ends when an incorrect sequence is selected.
